# 未准备审核草稿保存与恢复

2026-11-04，仅源码文档与人工审阅；没有编译、类型检查、测试、运行产品/浏览器/接口/数据库或发布。

## 草稿与原审核分离

审核表单提供 Save unfinished review in this browser 和 Export current unfinished review，不要求选择决定、填写完整理由或确认审核。独立的 `/proposals/recover-review-draft` 页面可查找、按键读取、导入及导出草稿，不依赖建议仍处于 proposed 状态。建议目录、审核表单和原审核恢复页均提供入口。独立页面只供审阅和导出；继续编辑需打开同一建议的当前审核表单并重新选取草稿。

独立 v1 格式为 `{schema_version:1,kind:'proposal-review-editing-draft',binding,request_key,saved_at,proposal_id,expected_revision,decision,reason}`。保存完整原网关及 tenant/workspace/project/actor/client、原请求键、规范 UTC 保存时间、建议 ID 和原审核版本。决定允许空字符串、confirm、reject；理由保留最多 2000 字符的原始空白及不完整文字，不执行 trim 或非空校验，拒绝 NUL 和孤立代理字符。建议 ID、版本和原键沿用审核的严格限制，顶层及绑定拒绝未知/缺失字段；有限 JSON、规范正文、漂亮排版文件均最多 32 KiB。

草稿不携带确认勾选、权限、令牌、审核结果或来源有效性证明。文件中的绑定只用于匹配当前可信身份，不授予权限；草稿、已准备原审核、创建草稿及回执格式不互换。

## 本地保存与发现

独立 IndexedDB `planemem-proposal-review-editing-drafts` v1 包含 drafts 与 directory，槽键绑定完整原身份和请求键，最多 16 KiB。目录最多 4 KiB，仅含原键、保存时间、建议 ID、版本和决定，不包含理由。保存时单事务核对既有双槽，只添加缺失内容；同键同文保留最初保存时间，异文、损坏或半槽拒绝，不覆盖或修复。新写入完整读回并等待事务提交后才报告成功。

目录按当前完整绑定范围每页最多 20 份，按槽键而非时间排序，返回前核对每份完整正文和摘要；第 21 份仅用于判断续页。选取后重新读取并匹配所选摘要；按键读取也核对完整双槽。缺库读取不初始化，缺项仅表示当前未见，不能推断是否发送过审核。分页不是跨页快照；完整备份及逐份移除见下文，批量/自动容量清理仍缺。

## 明确审阅与恢复

浏览器读取或导入文件只生成候选；当前编辑字段保持不变。页面展示完整理由、决定、原建议/版本/键/身份及保存时间，完整 JSON 可复制，候选可单独导出为 `proposal-review-editing-draft.json`。文件读前/读后核对 32 KiB 和实际长度，使用严格 UTF-8，再验证全部结构和原绑定。失败保留当前字段及此前候选，撤销旧恢复确认。

只有候选建议 ID 和版本均等于当前表单时才提供恢复按钮；用户明确勾选替换当前字段后，先只读查询同键原审核。不存在原审核时恢复原决定、原始理由和请求键，撤销准备确认；存在完整同文原审核时进入固定原请求页面，不自动保存或发送。判断同文时用既有规则规范化候选理由，再比较完整原请求；同键异文、损坏或无法查询则拒绝恢复。准备动作也重新检查同键原审核，避免恢复后另一标签页新增原请求被当成可替换内容；真正发送前既有原文保存核对仍是最后一道门禁。

恢复不更改候选的旧版本来适应当前建议。版本变化或审核已完成时仍可从独立页读出并导出文字，但不能直接把该草稿作为当前审核。重新编辑任一决定或理由分配新请求键并撤销确认，旧浏览器副本保留；未改动的重复保存保持首次时间。来源及权限继续由当前页面和实际发送时的服务端核验，草稿恢复不查询审核回执，也不证明原审核未发送或已取消。

## 操作期限与剩余范围

手动草稿读取、保存、文件载入、下载和恢复与当前表单准备动作共享互斥；操作期间禁止修改字段，开始草稿操作即撤销准备/恢复确认并暂停自动保存。下述自动保存不锁定输入。草稿区在审核 form 外，草稿查找框的回车不会隐式准备审核。整个异步动作最多 30 秒，库打开和事务各 10 秒；卸载中止本地等待并释放互斥，迟到结果不覆盖后续操作。未知手动保存结果保留当前文字及原键，可导出或按同键重新保存核对；不断言事务回滚。

本轮新增浏览器结构的源码，未初始化或迁移实际数据库，无服务端 schema 或依赖变化。可选择开启的自动保存见末节；草稿批量/自动清理、容量保留、跨范围迁移/同步、历史自动保存/整批备份清理或运行兼容证据仍缺。后续整批备份与恢复、逐份移除见下文，R-009/P7-01 仍未完成。

## 当前范围整批备份与恢复

审核表单的草稿区和独立草稿找回页增加 Back up or restore all manually saved review drafts。仅包括当前完整原网关及五字段身份范围内手动保存的审核编辑草稿；不包含独立自动副本、正在输入的文字、已准备原审核、创建草稿或历史回执。需要包含当前输入时先单独保存手动草稿。全部读到的草稿为完整集合，超限或损坏时拒绝整批，不静默截断。

独立 v1 文档 `{schema_version:1,kind:'proposal-review-editing-drafts-backup',binding,entries}` 最多 100 份、规范 JSON 最多 4 MiB；文件封套仅含 document 和 document_sha256，最多文档限额加 1024 字节。每份条目仍受单份 32 KiB 格式约束，必须匹配文档原绑定，按完整存储键严格递增，重复、乱序、超长键拒绝。保留空决定、原始未完成理由、原建议/版本/键及 saved_at，不规范化编辑文字或修改保存时间。

规范 SHA-256 覆盖完整文档、身份与所有保存时间；文件仅在严格 UTF-8、有界读取、格式/绑定/顺序及摘要均通过后成为候选。摘要用于检查内容一致，不证明来源、权限、是否曾发送或是否成功审核。文件名为 proposal-review-editing-drafts-backup.json，不与原审核备份互换。

prepareReviewEditingDraftsBackup 在同一只读事务计数完整范围的正文和目录，并读取核对每份双槽；数量不等、孤立槽、半槽、损坏或超过容量均拒绝。完整读完后再生成规范摘要；缺库返回空备份且不初始化。页面可逐份查看决定、完整理由、保存时间、版本和原键，保留备份供独立下载。空备份允许下载/比较，但不提供恢复按钮。

Compare with saved review drafts 只读比较文件里的全部目标槽，逐份展示 missing、same 或 different。比较包含保存时间，因此仅 saved_at 不同也视为冲突；这与单份重复保存保留已有时间的规则不同。目标损坏或半槽拒绝完整比较，不能只跳过损坏记录。比较不写库、不替换当前字段、不加载某份草稿进入编辑。

确认绑定备份摘要及当前页面存储变化序号。Restore missing review draft copies 会重新核验文件摘要，并在一个读写事务中预检全部目标：完整同文保留，仅缺失才写，任何异文/保存时间冲突/损坏拒绝整批。所有新写后重新完整读回全部目标，等待提交后才报告新增及保留数。只补文件中缺失的草稿，不删除目标额外内容；空集合不初始化库，非空显式恢复可创建原有 v1 库结构。

备份与单份读取/保存/下载/恢复、表单准备共享页面互斥，使用同步状态阻止渲染前重复操作。保存或备份恢复尝试立即失效旧目录、草稿替换确认及备份比较/确认；原候选和当前输入仍保留，需重新查找目录或比较备份。恢复结果未知时保留完整备份，不能直接沿用上次确认；需重新比较并明确决定是否再次补入。新的加载/准备/比较也撤销备份旧确认。

整个备份动作受 30 秒本地期限限制，库打开/事务各 10 秒；哈希或文件读取迟到后不能继续写入。卸载中止本地等待并释放互斥，不应用迟到结果，超时不保证已回滚。恢复文件到另一浏览器仍须恢复原完整绑定，之后从目录单独审阅草稿才可恢复字段；本功能不准备、发送或查询审核，也不自动同步、清理或改写当前编辑内容。

该手动备份增量沿用原草稿库结构，无 schema 或依赖变化。草稿批量/自动清理、自动备份、容量保留、跨范围联合迁移、历史自动保存/整批备份清理及真实浏览器恢复证据仍缺；逐份移除及可选自动保存见下文。只有源码文档和人工审阅，没有编译、类型检查、测试、运行浏览器/接口/数据库或发布。

## 逐份审阅并移除浏览器草稿

审核表单及独立草稿找回页的完整候选下新增 Remove this browser draft copy。候选记录来自浏览器还是单份文件，以及读取时的存储变化序号；只有成功读取正文和目录的浏览器候选、且之后没有本页存储改变，才可勾选独立移除确认。单份文件载入不会获得删除资格，需使用 Read current browser draft again 重新完整读取并审阅当前副本。

页面保留候选的原建议 ID、版本、键、完整原绑定、原始决定/理由及保存时间，仍可单份导出或复制完整 JSON。读另一份草稿、重读或导入单份文件开始时即撤销旧移除资格，缺失/失败时保留此前候选但不能直接删除。成功重读建立新候选并清除历史移除状态，必须再次勾选确认；不会沿用此前文件或不同内容的确认。

removeReviewEditingDraft 使用完整候选规范原文，在同一读写事务重读正文和目录，验证原绑定、原键和全部内容，包括 saved_at；只有双槽与候选完全一致才删除，随后读回确认两槽均不存在，等待事务完成后才报告 removed。仅保存时间不同也拒绝删除，不能使用单份重复保存时的时间保留规则放宽比较。半槽、损坏、同键异文或目录不一致一律拒绝，不强制清理或修复。缺库不初始化，两槽已缺失只返回 not-present，不证明历史移除成功或审核未发送。

移除开始即撤销草稿替换与删除确认，失效目录、备份比较/确认和当前移除资格。结果未知时保留候选及当前输入，不能直接重复删除；要先重新完整读取审阅，并再次确认。已确认 removed 或 not-present 后也必须重读才能产生新的移除动作。所有草稿/备份操作共用同步互斥，编辑当前理由或决定也撤销旧移除勾选；卸载中止等待并忽略迟到结果。整个动作最多 30 秒、库打开/事务各 10 秒，超时不能断言已经回滚。

此操作只移除本浏览器中的该份编辑草稿，不改当前编辑字段、不删除已准备原审核或其他标签页的内存内容、不撤回/取消/发送审核、不读回执；导出文件和备份保留。草稿即使对应的建议已完成或版本变化，仍可在独立找回页审阅后移除本地副本。候选保留在本页供导出或明确恢复字段；之后显式保存或备份恢复仍可能重新创建该草稿，不属于永久封禁或全局遗忘。

本增量未实现批量删除、自动清理/容量保留、损坏槽强制删除或跨范围清理；无 schema/依赖变化，仅源码文档人工审阅，未编译、类型检查、测试、运行产品/浏览器/接口/数据库或发布。

审核完整历史观察的显式浏览器留存、文件导入导出及独立找回已补，详见[审核历史观察留存与找回](proposal-review-history-runtime.md)；历史操作不改变原请求或审核状态。

## 可选择开启的审核草稿自动保存

2026-11-04 增量：当前建议审核表单可勾选 Automatically save this unfinished review in this browser，初始关闭，不跨重载保存开关。用户开启后约1.5秒无新输入时保存当前原决定/理由，允许尚未选择决定和空白理由。每次开启产生新的UUID v4自动会话，持续输入更新该会话最新副本；每次编辑仍产生新的审核请求键并撤销准备确认。保存的只是未准备审核草稿，不含确认勾选或批准结果；即使留存的决定为confirm，实际准备与发送仍受当前建议版本、来源、能力及明确确认限制。

独立IndexedDB `planemem-proposal-review-editing-autosaves` v1使用drafts/directory，正文复用既有32 KiB格式，完整保留原绑定、建议ID/版本/请求键、原始理由和保存时间。目录最多4 KiB，仅含会话ID、请求键、时间、建议ID、版本、决定，不含理由；槽键最多16 KiB，绑定原网关及五字段身份与会话ID。共享 `draft-autosave-store.ts` 提供事务操作，创建和审核通过固定的独立布局/编解码器/摘要适配隔离，创建库名、格式及原入口保持不变。

首次自动写入必须双槽均缺失，后续必须与上次确认的完整原文（包括时间）一致；双槽损坏、删除、正文/目录改变均拒绝，不覆盖他人会话或重建已删会话。正文和目录同写事务更新，完整读回后等待事务完成才确认；同一编辑会话只允许一个自动写入在途。共享 `use-draft-autosave.ts` 负责延迟、串行、暂停和状态，严格按捕获时的全部输入匹配确认；旧保存结果不会标记后来输入的文字已保存。未保存/保存中/已确认/未知均显示在表单，自动写入期间继续允许输入。

任何手动草稿操作、查找、审阅、导出、删除、恢复或手动整批备份，在取得既有互斥后同步暂停自动写入并取消等待。准备期间不启动新自动写入；转入固定原审核后卸载自动编辑区。父表单以完整绑定、建议ID/版本挂载，变化时取消旧等待，旧回执不改变新表单。取消/超时/配额或校验失败可留下已提交副本，停止自动写入并保留输入，提示查找或导出；不自动重试未知会话，再次开启创建新会话。不依赖离开页面时异步补存，等待中的文字不能声称已保存。

Find automatic review drafts / Next automatic review drafts同时用于审核表单和独立 `/proposals/recover-review-draft` 页面。独立页没有编辑器、开启开关或自动写入，建议已结束/版本变化时仍可按原身份查找并导出本地副本。目录按会话键排序，每页最多20条完整正文/目录核验，第21条仅判断续页；所选读取再次匹配所选摘要，其他页面更新导致失效时须重新查找。手动请求键读取只查手动快照库，自动副本需由独立目录选择，界面标明候选类型。

自动候选复用全部原始字段审阅、JSON复制、逐份文件导出及明确恢复流程。只有同建议/同版本的当前审核表单可恢复；先查询同键已准备原审核，完整同文则打开固定原请求，不存在时恢复原编辑字段，异文或查询失败拒绝。恢复不会接管旧自动会话，不自动开启保存，也不会调整旧版本适应当前建议。来源/权限失效继续由当前准备/发送校验，不借自动副本绕过确认。

自动候选也可独立确认移除，复用原页面移除资格：必须刚从浏览器完整读取且之后没有本页存储变动，失败重读、文件导入及存储修改均撤销资格。实际删除精确比较整个双槽后删除并读回，缺库不初始化、缺项只报告本次未见。尝试即撤销确认、目录和资格，未知保留可导出的候选；重新查找并完整选择后才可再次删除。另一个写者随后发现其已确认槽缺失则停止，当前页也已暂停，不自动复活被删副本。

自动副本与手动不可变快照及整批备份独立，备份界面明确不包含自动副本；要归档可逐份导出，或在匹配审核表单明确恢复后手动保存。每个会话只保留最后一次成功写入，没有逐次输入历史、自动副本整批备份/批量清理/容量保留/远端同步。操作仍有30秒总期限及打开/事务各10秒；新增浏览器结构仅源码，无服务端schema/依赖变化。仅开发与人工审阅，未编译、类型检查、测试、运行产品/浏览器/数据库或发布，运行及兼容证据仍待后续。
