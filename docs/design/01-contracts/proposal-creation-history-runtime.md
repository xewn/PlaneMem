## 完整观察与当前提交分开

固定原创建页接收并核验有效发送回执或只读查询封套后，保存一份内存观察：完整原请求、完整响应、响应来源和本地观察时间。发送动作返回完整封套而非仅data，浏览器再次核验revision、ETag、server_cursor、来源与命令回执；查询继续核对原身份、键和完整草稿。错误/超时/取消或无效响应不构造历史。

最新观察与最近已确认观察独立保留。创建确认后仍允许用户明确只读查询，后续not-observed或查询失败不清除原已确认回执，不重新开放发送入口。后续recorded须与已确认观察的建议ID/状态/版本/事件ID/事件时间/cursor一致，trace与replayed不用于比较；不同则保留新观察供导出、提示冲突并维持旧确认。页面分别保留最新观察、已确认观察、最近自动留存尝试及独立审阅候选；没有无限留存队列，其他轮次需显式保存/导出或预先开启后述自动留存。每次新收到的结果具有自己的观察时间和trace，导出/重载不重写时间或响应。

## 格式、限额与校验

独立v1文档为`{schema_version:1,kind:'proposal-creation-observation',original,observed_at,source,receipt}`；source仅submission或receipt-query。original使用既有1 MiB固定创建请求格式，保留网关及五字段身份、原键、完整草稿/来源/派生关系。observed_at为规范UTC毫秒时间，表示页面观察时间，不替代服务端事件时间。

submission的receipt最多64 KiB，严格包含schema_version、trace_id、data、source_refs、revision、etag和server_cursor。data严格包含proposal_id/status/revision/event_id/occurred_at/replayed；状态proposed、revision=1，外层版本和ETag一致，cursor正安全整数，事件与建议ID为ULID，事件时间规范UTC，来源恰为该建议的revision 1。发送响应不包含原草稿，关联来自原页面操作与服务器动作回传的同一完整原请求；文件不能证明该关联真实。

receipt-query的receipt复用2 MiB原创建回执封套解析，绑定original中的identity/request_key/draft，区分recorded与not-observed。not-observed不含结果或来源；recorded保留原建议ID、事件、版本、时间、cursor与current_state='not-checked'。整体观察最多4 MiB，文件封套`{document,document_sha256}`最多4 MiB+1024字节。文件、文档、发送回执拒绝缺失/多余字段；解析前后规范JSON必须相同，禁止丢弃或规范化原文中的字段。

规范JSON按对象键排序、数组顺序保留；SHA-256覆盖完整观察。导入先检查文件大小，读取后核对实际字节数，严格UTF-8，再核验完整结构、原绑定和摘要。不接受原请求文件、审核历史或备份文件冒充创建历史。摘要只说明内部一致，不认证来源、权限、原请求与发送响应的真实关联或当前建议状态。

## 审阅、导出与取回原请求

当前创建页提供Inspect latest received result for saving or export，存在不同已确认观察时另提供对应入口。准备候选先固定完整规范文档，再计算摘要；哈希失败不改变已收到的结果。面板显示来源、观察时间、原身份、请求键、trace、摘要；已确认结果额外展示建议/事件/版本/时间/cursor，未见结果明确不证明失败或取消。完整文件可展开复制，亦可明确保存浏览器副本，见末节。

Export inspected creation history重新核验完整候选后请求下载`proposal-creation-history.json`。Export its original request从同一已核验候选提取既有格式的`proposal-original.json`，可通过原创建恢复页载入后显式查询回执或按原规则确认重试；提取本身不保存浏览器副本、不查询或发送。下载只报告已发起，需用户确认文件实际落盘；失败保留完整候选供复制或重试。

`/proposals/creation-history`提供独立浏览器历史和文件审阅页，通过当前可信绑定限制载入范围，不依赖当前建议仍存在或可审核。原创建页和创建恢复页提供导航。独立页面初次获取绑定仍需要当前登录；文件校验在浏览器进行，不把文件上传为审核证据。导入或浏览器读取只能改变历史审阅候选，不能回填父页面的已确认状态、禁止/解除发送或替换原请求；不通过导入文件自动获取发送资格。

## 新收到结果的自动留存

固定原创建页的Automatically save newly received creation results in this browser默认关闭，仅在本页面内有效；开启不查询、发送或补存旧观察，不保存偏好供其他页面或下次打开沿用。仅后续完整校验通过的发送/只读查询结果触发，包含not-observed及与旧确认事实不同的新查询观察；无效/不可用响应不触发。新观察仍先进入内存并更新对应结果消息，旧已确认回执继续按原规则保留，随后尝试本地保存，因此历史库失败不冒充网络/创建失败。

自动留存复用既有4 MiB观察、原绑定/时间/trace/完整请求响应、规范摘要与双槽幂等保存，已有完整同文保留、异文/损坏拒绝，完整读回并等待提交。发送/查询的30秒等待结束后，留存具有独立30秒本地期限，仍持有原页面同步锁；库打开/事务各10秒。Stop waiting on this page在本地留存阶段仅停止该次等待，不取消已收创建结果，也不保证撤回已提交存储。卸载中止等待并忽略迟到结果，不尝试离开时补存。

本地尝试状态单独显示saving/saved/unknown与确认后的摘要。失败、停止或超时关闭自动开关并保留完整原观察；原创建结果/冲突提示不改写。未知未解决前不能重开自动留存，后续新响应不会覆盖该失败候选。Retry saving the retained observation locally仅以相同原观察时间/响应/摘要重新执行本地幂等保存，不查询或发送；成功后允许用户重新开启，但不自动重开。用户也可从历史面板审阅或导出失败观察；面板手动保存不冒充这次自动尝试已确认，仍可显式补存确认同文。

每次自动留存及补存开始更新父页外部存储代次；历史面板合并本地与外部代次，在清理effect之前就使旧单份删除、所选整理和备份比较/恢复资格失效，再清空旧目录及确认。已审阅单份、子集及备份保持可导出。最近自动留存观察与最新/确认观察引用相同时不重复入口，否则单独提供Retained automatic-save observation，确保后续响应不挤掉失败副本。不改原请求库、草稿、审核历史或远端记录，不解除其他页面未知结果；无schema/依赖变化，仅源码文档人工审阅，未编译、类型检查、测试、运行或发布。

## 浏览器保存目录与单份移除

Save inspected creation history in this browser对当前完整候选显式保存，复用既有文件格式和摘要，不改变原观察时间、原请求/响应或trace。独立IndexedDB `planemem-proposal-creation-history` v1使用observations/directory双槽，键包含完整原网关/五字段身份及观察SHA-256；目录只含摘要、原键、可空建议ID、响应来源、历史结果及观察时间。单文件4 MiB+1024字节，目录4 KiB、键16 KiB。不同观察不会按同请求键互相覆盖。

写入前完整核验原绑定/文件摘要，同写事务检查双槽：已有完整同文保留，缺失才同时add正文和目录，已有异文、半槽或损坏拒绝，完整读回并等提交才报告成功。重复保存同一内容幂等；不知道前次是否提交时可显式用同一候选重试，不自动修复坏槽。保存只写历史库，不补原请求、编辑草稿、审核历史或服务器记录。

Find saved creation history从当前绑定起始位置读取，每轮最多5份；每份可含较大完整草稿及查询中的同一草稿，因此正文总量由5×单文件上限约束。使用单只读事务按摘要键读取正文和目录并核对规范内容、槽位与原绑定，事务完成后全部核验SHA-256才展示匹配目录。第6项仅读取键判断续页，不作为已核验内容返回；next携带最后扫描摘要及原筛选，不按时间排序、不自动遍历、不承诺跨页快照，也不把目录当作全库损坏审计。损坏或超时整页失败，不显示部分结果。缺库返回空页且不初始化。

## 组合筛选与继续查找

当前创建页及独立历史页的Find saved creation history提供建议ID、原请求键、历史结果、响应来源和UTC观察日期范围的可选交集筛选。建议ID沿用ULID精确校验，请求键沿用1–255非空白字符规则，不自动trim/改大小写；结果仅recorded/not-observed，来源仅submission/receipt-query。query严格包含proposal_id/request_key/status/source/observed_from/observed_through/after，空条件为null，after为null或64位小写十六进制摘要；未知/缺失字段及非法值在打开库前拒绝。日期边界见下节。

建议ID来自已记录的创建回执；not-observed没有建议ID，因此带ID条件时不会匹配未见回执观察。submission只对应recorded，矛盾组合自然返回空匹配，不转换条件或推断建议当前状态。匹配结果只在本轮全部完整双槽和内容摘要通过校验后返回，未匹配项也必须完整有效；坏记录不能因为不匹配而被跳过。

每次扫描仍最多5份、返回0–5条匹配，scanned为实际校验数。Continue history search携带本轮原条件及最后扫描摘要排他续读，按扫描位置而非最后匹配项推进；空匹配页仍可继续。界面区分本批无匹配和本次读取已到末尾，展示扫描/匹配数；末尾只针对该次读取，不包含先前页或后来新增项。新搜索从头开始，改条件立即清空旧目录和续页、撤销单份删除资格及确认，同时保留已审阅的完整候选。读取期间禁止改条件，沿用原页面同步互斥及30秒等待。

按摘要直接读取与单份文件审阅不受目录条件限制。筛选影响目录及其所选整理，整批备份仍读取当前完整绑定下全部已保存记录；不自动导出、保存、恢复、删除或查询/发送建议。不改浏览器v1格式、schema或依赖；只有源码文档与人工审阅，未编译、类型检查、测试或运行浏览器/数据库。

## 观察日期范围
