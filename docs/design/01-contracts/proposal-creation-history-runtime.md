# 原创建结果历史留存与找回

2026-11-04，仅源码文档与人工审阅，未编译、类型检查、测试、运行产品/浏览器/接口/数据库或发布。

## 完整观察与当前提交分开

固定原创建页接收并核验有效发送回执或只读查询封套后，保存一份内存观察：完整原请求、完整响应、响应来源和本地观察时间。发送动作返回完整封套而非仅data，浏览器再次核验revision、ETag、server_cursor、来源与命令回执；查询继续核对原身份、键和完整草稿。错误/超时/取消或无效响应不构造历史。

最新观察与最近已确认观察独立保留。创建确认后仍允许用户明确只读查询，后续not-observed或查询失败不清除原已确认回执，不重新开放发送入口。后续recorded须与已确认观察的建议ID/状态/版本/事件ID/事件时间/cursor一致，trace与replayed不用于比较；不同则保留新观察供导出、提示冲突并维持旧确认。页面最多保留最新观察、已确认观察与一份独立审阅候选；要保留其他轮次需及时导出，没有自动留存队列。每次新收到的结果具有自己的观察时间和trace，导出/重载不重写时间或响应。

## 格式、限额与校验

独立v1文档为`{schema_version:1,kind:'proposal-creation-observation',original,observed_at,source,receipt}`；source仅submission或receipt-query。original使用既有1 MiB固定创建请求格式，保留网关及五字段身份、原键、完整草稿/来源/派生关系。observed_at为规范UTC毫秒时间，表示页面观察时间，不替代服务端事件时间。

submission的receipt最多64 KiB，严格包含schema_version、trace_id、data、source_refs、revision、etag和server_cursor。data严格包含proposal_id/status/revision/event_id/occurred_at/replayed；状态proposed、revision=1，外层版本和ETag一致，cursor正安全整数，事件与建议ID为ULID，事件时间规范UTC，来源恰为该建议的revision 1。发送响应不包含原草稿，关联来自原页面操作与服务器动作回传的同一完整原请求；文件不能证明该关联真实。

receipt-query的receipt复用2 MiB原创建回执封套解析，绑定original中的identity/request_key/draft，区分recorded与not-observed。not-observed不含结果或来源；recorded保留原建议ID、事件、版本、时间、cursor与current_state='not-checked'。整体观察最多4 MiB，文件封套`{document,document_sha256}`最多4 MiB+1024字节。文件、文档、发送回执拒绝缺失/多余字段；解析前后规范JSON必须相同，禁止丢弃或规范化原文中的字段。

规范JSON按对象键排序、数组顺序保留；SHA-256覆盖完整观察。导入先检查文件大小，读取后核对实际字节数，严格UTF-8，再核验完整结构、原绑定和摘要。不接受原请求文件、审核历史或备份文件冒充创建历史。摘要只说明内部一致，不认证来源、权限、原请求与发送响应的真实关联或当前建议状态。

## 审阅、导出与取回原请求

当前创建页提供Inspect latest received result for saving or export，存在不同已确认观察时另提供对应入口。准备候选先固定完整规范文档，再计算摘要；哈希失败不改变已收到的结果。面板显示来源、观察时间、原身份、请求键、trace、摘要；已确认结果额外展示建议/事件/版本/时间/cursor，未见结果明确不证明失败或取消。完整文件可展开复制，亦可明确保存浏览器副本，见末节。

Export inspected creation history重新核验完整候选后请求下载`proposal-creation-history.json`。Export its original request从同一已核验候选提取既有格式的`proposal-original.json`，可通过原创建恢复页载入后显式查询回执或按原规则确认重试；提取本身不保存浏览器副本、不查询或发送。下载只报告已发起，需用户确认文件实际落盘；失败保留完整候选供复制或重试。

`/proposals/creation-history`提供独立浏览器历史和文件审阅页，通过当前可信绑定限制载入范围，不依赖当前建议仍存在或可审核。原创建页和创建恢复页提供导航。独立页面初次获取绑定仍需要当前登录；文件校验在浏览器进行，不把文件上传为审核证据。导入或浏览器读取只能改变历史审阅候选，不能回填父页面的已确认状态、禁止/解除发送或替换原请求；不通过导入文件自动获取发送资格。

## 操作边界与剩余范围

准备、导入、导出及浏览器历史操作共用30秒整体等待；父创建页通过同步互斥阻止它们与原请求保存/发送/查询并发，并清除旧发送确认。历史操作使用自己的等待控制器，原创建的停止等待按钮仅在其自身操作期间显示。卸载中止等待、释放本次所持锁并忽略迟到文件或哈希结果；失败保留旧审阅候选、源文件及已收到的观察。仅新候选完整核验成功后替换当前审阅项。

新增独立浏览器v1库仅为源码结构，无服务端schema、迁移、依赖或公共服务器API变化。创建历史整批备份/恢复/清理、自动留存、筛选、跨页面协调与运行兼容证据仍缺。R-009/P7-01保持未完成，源码不作为已运行验证证据。

## 浏览器保存目录与单份移除

Save inspected creation history in this browser对当前完整候选显式保存，复用既有文件格式和摘要，不改变原观察时间、原请求/响应或trace。独立IndexedDB `planemem-proposal-creation-history` v1使用observations/directory双槽，键包含完整原网关/五字段身份及观察SHA-256；目录只含摘要、原键、可空建议ID、响应来源、历史结果及观察时间。单文件4 MiB+1024字节，目录4 KiB、键16 KiB。不同观察不会按同请求键互相覆盖。

写入前完整核验原绑定/文件摘要，同写事务检查双槽：已有完整同文保留，缺失才同时add正文和目录，已有异文、半槽或损坏拒绝，完整读回并等提交才报告成功。重复保存同一内容幂等；不知道前次是否提交时可显式用同一候选重试，不自动修复坏槽。保存只写历史库，不补原请求、编辑草稿、审核历史或服务器记录。

Find saved creation history从当前绑定起始位置读取，每页最多5份；每份可含较大完整草稿及查询中的同一草稿，因此正文总量由5×单文件上限约束。使用单只读事务按摘要键读取正文和目录并核对规范内容、槽位与原绑定，事务完成后全部核验SHA-256才展示目录。第6项仅读取键判断续页，不作为已核验内容返回；next为最后返回摘要，不按时间排序、不自动遍历、不承诺跨页快照，也不把目录当作全库损坏审计。损坏或超时整页失败，不显示部分结果。缺库返回空页且不初始化。

目录条目需要Inspect saved creation observation再次读取完整双槽、精确核对原目录摘要，再核验内容SHA-256；也可通过64位小写十六进制摘要直接读取。缺项保留原审阅副本，不说明服务端结果。读取或载入失败不替换旧候选，也不能沿用旧删除资格。浏览器载入与文件导入一样只表示历史副本，不回填当前创建确认。

单份移除要求本轮从浏览器完整重读并审阅，再独立勾选确认。资格绑定候选摘要/正文、读取来源与本地存储代次；文件/收到的观察/刚完成保存均无直接删除资格。任何保存或删除开始递增代次、清空旧目录和确认；重新查目录/读取、改摘要输入或尝试载入新候选清除删除资格。所有操作都撤销旧勾选，存储失败也不恢复旧资格。

删除前重新核验完整候选与原绑定/摘要，再在同写事务核对当前完整双槽必须与审阅原文及目录逐字节相同；全部缺失仅返回not-present，不解释前次是否成功，异文/半槽拒绝。精确删除双槽、读回均缺失并等事务提交才报告removed；缺库不初始化。未知结果可能已提交，保留可导出的完整候选，必须重新读取审阅才可再次移除。

移除不删除原请求、草稿、审核/回执、其他页面内存或下载文件，不提交、撤回或取消建议。后续显式保存同一候选可重建已删副本；浏览器驱逐或清理也可能使保存内容消失，独立导出仍必要。库打开/事务各10秒，文件/哈希/存储合计30秒，卸载取消本地等待，不承诺已开始的事务被撤回。仅源码文档，未实际创建库、运行页面、编译、类型检查、测试或发布。
