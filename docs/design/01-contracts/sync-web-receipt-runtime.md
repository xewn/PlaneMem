## 用户入口

工作台侧栏新增 Sync receipts，指向 `/sync/receipt`。页面读取已有登录展示信息但不自动取得同步身份、查询回执、上传、确认游标或操作本地队列。顶栏在该入口显示只读/按需查询，避免未查询时显示 fresh query 或 Connected。

用户导入/粘贴完整 `{identity,event}`，或既有 `workctx.sync-event-receipt` v1 文件。输入读取上限为 `SYNC_EVENT_RECEIPT_FILE_BYTES`（2 MiB + 8192 字节）；文件先按声明大小检查，再完整严格 UTF-8 解码和字节复核。查询内容复用 `parseSyncEventReceiptQuery`，规范正文仍限 1 MiB + 16 KiB；文件复用共享完整文件/回执解析，并通过浏览器 WebCrypto 独立计算文档 SHA-256。非法文件不降级为普通查询，不补空 event 或替换身份。导入后的历史封套保留原查询 trace，单独展示“Imported historical receipt”，摘要一致不表示来源认证或当前服务器确认。

原查询载入后固定完整身份和 event，展示事件 ID/类型、五字段身份，支持查看/复制完整 JSON、准备原查询下载。用户明确点击 Check original delivery 才发一次请求，使用当前登录会话中的凭据查询原账号/客户端/项目绑定；凭据不匹配由 Gateway 拒绝。页面不生成新事件、幂等键或假定本地队列状态，不根据当前身份重建缺失原内容。

每次成功完整查询显示 recorded/not-observed，并保留原接受/冲突状态、服务端事件/游标、记录时间、原投递 trace 和本次查询 trace。recorded 不证明源实体已应用或当前冲突已解决；not-observed 不证明失败，也不授权重发。查询失败只增加错误提示，原查询和此前完整成功响应保留；此前结果继续标注“Most recent completed lookup”，不混同失败的新请求。冲突链接仅从本次完整远端结果提供，在新标签页读取当前详情。

页面使用忙碌锁防止同时载入/查询/导出/浏览器保存与目录读取；固定载入内容后只能在新标签页启动另一笔查询，立即设置原文锁避免重新渲染前二次载入替换。离开页面会取消当前等待，异步导入/摘要/查询结束后不再写回卸载页面或启动下载。单次点击查询有 35 秒浏览器本地预算，响应完整解析后再检查预算，迟到内容不覆盖此前结果。不自动重试、轮询或持久写入；浏览器保存必须显式点击，刷新/关闭前仍建议保留独立原文件。

## 浏览器原查询保存与恢复

Save original in this browser 显式保存当前固定 `{identity,event}`。独立 IndexedDB `planemem-sync-originals` v1 有 `originals` 与 `directory` 两个无 keyPath、自增或索引的存储；原文为完整规范 JSON，目录为最多 16 KiB 的 v1 元数据 JSON（完整五字段身份、event_id、event_type、原文字节数）。键为五字段原身份加 event_id 的固定 JSON 元组，不依赖当前账号，也不使用有歧义的字符串拼接。目录不存正文或回执。

保存先完整共享解析，在同一 readwrite 事务读取两槽的存在性和内容。两槽同时缺失才用 add 添加，随后完整读回并核对原文、身份/事件键及目录；只在事务完成后报告 saved。已有槽须两边同时存在、完整核验且原文序列化一致，才能报告 already-saved；同槽异文、单边缺失、非字符串或损坏拒绝，不 put、删除、覆盖或自动修复。事件内部 JSON 属性顺序沿用原规范序列化，不将任意重排正文视为可替换原文。并发写由同范围事务串行保护；不存在存储与网络原子性。

Browse saved originals 只在明确点击后读取当前浏览器目录，按 IndexedDB 字符串主键顺序每页 20 条，最多再读取并核对一条前瞻；续页从最后展示键严格向后，支持回到首屏刷新，不全量扫描原文。目录在同一只读事务中读取，跨页是当前状态，不是冻结快照。空库/空页明确为空，失败保留旧目录并标明本次读取失败。目录展示跨原账号/项目的本地元数据，只作定位提示，不证明正文有效、服务器状态或当前会话权限。

Load complete original 在单一只读事务按所选完整键读取原文和元数据，重新共享解析、核对规范 JSON、字节长度、完整身份/事件/类型及所选目录元数据；缺失明确提示，变化/损坏拒绝载入。载入成功后仍须审阅并显式查询，不自动联系服务器，不将保存状态变成 recorded。查询继续使用已有原身份约束和 Gateway 授权；保存/恢复不需要将本地数据交给服务器。导入的历史回执和先前成功响应保持原页面语义，不随保存原文写入数据库，重载也不恢复为当前确认。

只读打开缺失数据库时中止首次 upgrade，返回空/缺失，不永久建立空库；只有显式保存可以初始化 v1。未知版本、缺失/多余存储、异常 schema 拒绝，不迁移。打开和事务分别有 10 秒单调本地预算及 AbortSignal；迟到打开关闭，取消后不启动新事务，事务异常尝试 abort，失败不等待无限期 abort 回调。事务回调没有异步摘要等待，避免请求队列空闲后自动提交。超过期限或取消可使提交结果未知，页面保留原查询和导出入口，不宣称保存没有发生。

浏览器存储会受配额、清理、隐私模式、设备/profile 和同源脚本影响；此功能不承诺永久备份、服务器签名或加密隔离。边界限制本次目录条数和解析字节，不限制数据库总量，也不能在浏览器结构化克隆前限制已经损坏的超大值。目录内容本身未做原文哈希认证，载入后的完整契约校验不代表服务器已接收。所有浏览器初始化、并发、取消、清理/配额行为仍无运行证据。

## 浏览器历史回执

本页最新完整查询可显式 Save this lookup in this browser；已核验的导入/恢复历史可显式 Save historical receipt in this browser。两者都保存既有 `workctx.sync-event-receipt` v1 文件，包含完整原查询和原结果；只保存原查询不会顺带保存回执，查询/导入成功也不自动写入。历史复制重新规范化时必须保持原文档摘要一致。保存不改变查询的 recorded/not-observed、本地队列状态或来源可信程度。

独立 IndexedDB `planemem-sync-receipts` v1 使用 `receipts` 和 `directory`，不升级或改写原查询数据库。文件槽键为完整规范文档的 SHA-256；相同文档幂等，不同查询 trace/结果产生独立槽，不用当前时钟覆盖旧观察。元数据为最多 16 KiB 的 v1 JSON，含五字段原身份、event_id/type、原查询 trace、历史 outcome 和完整文件字节数。此元数据仅供选择，目录上的 outcome 不代表本次服务器观察。

保存前在事务外完整规范化文档并计算摘要，随后用同一 readwrite 事务核对文件/目录存在性。相同内容只返回 already-saved；两边均缺失才 add 并读回，完整结构/键/元数据解析以及与预先计算摘要的完整文件逐字一致后，仍须等待事务完成才报告 saved。部分缺失、损坏、同摘要异文拒绝，不覆盖或修复。事务内不等待 WebCrypto；逐字一致把读回内容绑定至事务前已计算摘要的同一完整文档，避免空闲自动提交。

Browse saved receipts 在未载入原事件时显式读取跨账号/项目的本地目录，每页 20 条加一条已核对前瞻，按摘要字符串排序，明确不按时间排序，也不声明哪个结果最新。支持回到首屏刷新和续页，页间为当前状态；失败保留此前目录。该步骤不读完整文件、不计算文档摘要、不请求服务器。Load complete historical receipt 读取所选摘要槽中的完整文件和目录，在同一只读事务核对结构、键、规范序列化、字节数、原身份/事件/trace/outcome 及所选元数据，然后释放事务并独立计算文档摘要。摘要与所选键完全一致才载入；缺失与损坏区分，不拿目录状态替代正文。

恢复时从文件中的完整原身份/事件固定查询，显示 Saved historical receipt 和 Saved copy reports；文件导入仍显示 Imported historical receipt/File reports。历史不会赋给本页最新远端结果，显式查询仍走原同源代理与权限检查。恢复历史可以再次下载或复制完整 v1 JSON，保留文档摘要和原 trace；下载不证明实际磁盘保存。不同观察可能相互矛盾，用户应显式查询原事件，不根据旧文件自动重发、合并、确认游标或结算队列。

`browser-store.ts` 提取两类原存储共用的打开/事务/成对读取保护，原查询库名称、schema、键和保存语义不变；新历史库沿用只读缺库中止初始化、未知 schema 拒绝、打开及事务各 10 秒和取消保护。历史保存/完整载入另加 30 秒总本地预算，覆盖摘要准备、存储和最终核验；摘要工作无法物理取消，迟到完成必须再次检查预算，不能启动新的存储事务或更新卸载页面。预算不承诺同步解析的硬实时抢占。配额/超时/取消或提交失败保留原查询与完整响应，可能已经提交，提示不得声称完全未写入。

历史文件摘要校验只证明内容一致，不认证服务器；旧导入文件保存后仍是本地历史。没有本地可信 saved_at、来源签名、自动清理、批量删除/导出或全库修复，也不保证浏览器永久保存。新历史 schema 只写源码，未打开/创建数据库；原查询助手提取及历史并发/摘要超时/配额/取消/恢复/下载行为均未运行验证。

## 同源只读代理

新增 Route Handler `POST /sync/receipt/query`，不修改全局 Server Action 正文上限。该路径只转发既有 `POST /v1/sync/events/receipt`，没有新增 Gateway 写操作。请求须使用匹配工作台配置的 Origin、适用 same-origin fetch-site、专用 `x-workctx-sync-receipt:1`、受限 UUID trace 和 JSON 类型，拒绝 URL 参数、内容编码及写入/范围条件头。客户端不能提供其他上游路径或写键。

代理复用既有签名会话读取助手取得一次会话/范围快照，先要求有效登录，再取每进程最多两笔在途查询名额。原身份的三层范围必须与会话范围完全一致，actor/client 原值通过预期身份头发送；实际 token 验证、账号/客户端绑定、sync.write/admin、项目/来源可见性和入口审计继续由 Gateway 执行。本地会话范围仅作附加约束，不把未验证 JWT 展示信息视为授权。

请求完整读取最多 1 MiB + 16 KiB，检查适用 Content-Length；成功上游正文最多 2 MiB、错误最多 16 KiB，复用有界读取/严格 UTF-8 JSON、HTTP 200、完整长度与类型检查。上游响应头和正文 trace 必须匹配，成功复用完整 identity/event/状态/来源/receipt 校验。错误只从完整有界且 trace 一致的错误封套映射为 signin/denied/mismatch/invalid/busy/timeout/unavailable，不向浏览器透传原 message/details、凭据或原始上游正文。

代理从进入请求开始计 30 秒单调本地预算，将浏览器取消和同一控制信号传递到正文读取及上游 fetch，在会话读取后、请求前、完整响应后再次检查。会话在上游请求前和返回前检查过期。忽略取消的底层工作仍需结束才释放在途名额；本地同步解析与返回发送不能被中途抢占，预算不承诺硬实时中断。容量只覆盖已认证后的准备/读取，不包含整个进程的认证开销、响应网络发送、全局跨实例容量或数据库成本。

代理响应使用 private/no-store/no-transform、nosniff 和匹配 trace。浏览器再次有界读取（成功 2 MiB/错误 16 KiB）、核对 HTTP/头/完整原事件绑定后才展示；本地导入的历史结果不会通过此分支伪装成新查询。Gateway 错误及期限不更改原投递状态，也不自动结算 SQLite。

## 导出与兼容

Download original query 准备可交给 CLI `sync receipt --json-file` 的原 `{identity,event}`。Save receipt file 仅从本页面取得的完整远端回执构造共享 v1 文件，以 WebCrypto 摘要并完整共享解析；输出可供 CLI `outbox inspect-result --result-file` 离线查看，或本页面再次载入。文件不包含本地队列结算断言或服务器签名，原始 CLI 文件格式不变。

浏览器下载只代表准备并交给浏览器，不证明最终文件保存。失败时保留完整响应并支持复制；生成过的文件 JSON 也可复制。原查询和回执各自仅在显式点击保存后写入相应 IndexedDB，未保存内容仍留在页面内存，无新增服务端存储。WebCrypto 不可用或完整摘要不符时不能把文件标为核验成功。

该入口补充 Web 原同步回执读取、同浏览器原查询及历史回执的显式保存/恢复与审阅后逐条移除，尚不提供本地 SQLite 连接、旧缺身份记录追溯、跨设备队列恢复、批量查询、批量导出/损坏存储恢复/容量管理、SDK/MCP 文件适配或应用位点事务。现有断网/权限/异常响应/大文件/取消/浏览器保存与端到端证据均仍待运行，未生成验证结论。
