# 审核历史观察留存与找回

2026-11-04，仅源码文档及人工审阅；未编译、类型检查、测试、运行产品/浏览器/接口/数据库或发布。

## 完整观察而非当前状态

原审核页面接收有效发送回执或只读查询封套后，保留完整原请求、完整响应、响应路径和本地观察时间。最新观察与最新已确认观察分别保留；后续 not-observed 或查询异常不清除已确认历史结果。每次成功查询可产生不同 trace 的观察，不把多个结果覆盖为一个“最终状态”。页面只保留最新这两种内存候选及当前审阅副本，要保留其他轮次须逐次显式保存或导出；未有效返回的错误、超时或旧页面缺失封套不凭空重建。

Inspect latest received result for saving / Inspect retained confirmed result for saving 生成完整历史文件候选，之后可独立 Save inspected history in this browser 或 Export inspected history。不会自动保存，也不因本地保存失败改变已确认的审核结果。导入/浏览器载入的记录只进入历史面板，不回填原审核发送状态，不触发查询、重发或解除另一个页面的未知结果。

## 文件与校验

独立 v1 文档为 `{schema_version:1,kind:'proposal-review-observation',original,observed_at,source,receipt}`，最多 128 KiB；封套 `{document,document_sha256}` 最多文档限额加 1024 字节。original 为完整原审核格式，保留原网关、五字段身份、请求键、建议 ID、原版本、决定和理由。observed_at 是规范 UTC 本地观察时间，与回执事件发生时间分开，不强行推断时钟先后关系。

source 为 submission 时保存完整发送响应，包括 trace/source_refs、data、revision/etag/server_cursor/replayed，使用既有严格发送回执解析器核验；source 为 receipt-query 时保存完整只读响应，按原请求核验 recorded 或 not-observed。完整原请求仍限 32 KiB，完整回执仍限 64 KiB，顶层未知/缺失字段拒绝。规范前后内容必须完全一致，不能通过解析器丢弃字段或修改原文。

规范 SHA-256 覆盖完整文档，包含原身份、完整响应、trace 和观察时间。文件名 proposal-review-history.json；文件读前及读后检查大小与实际长度，严格 UTF-8，之后核验格式、原绑定与摘要。原请求、编辑草稿或整批备份文件不作为历史文件载入。

摘要只证明文件内部一致，不是服务端签名。用户可修改文档并重新计算摘要，因此浏览器/导入历史不授予权限，也不证明来源、当前建议状态或来源有效性。not-observed 是一次历史读取未见匹配回执，不表示审核失败、取消或允许重发；页面明确区分此类结果。历史 UI 显示原决定/理由、观察时间、事件时间、版本、event_id、server_cursor、trace 和完整可复制文件。

## 独立浏览器历史

IndexedDB `planemem-proposal-review-history` v1 使用 observations 与 directory 双槽；键包含原完整绑定和文档摘要，不用请求键覆盖不同观察。同一完整文件重复保存幂等，不同响应/trace/观察时间形成不同槽。摘要键最多 16 KiB，目录最多 4 KiB，只含摘要、原请求键、建议 ID、观察时间、响应路径及结果标签。

显式保存先有界校验完整文档及 SHA-256，再在单个读写事务重查双槽：已有完整同文保留，摘要同键异文、半槽、损坏或目录不一致拒绝；缺失才 add，完整读回并等待提交后才报告成功。异步哈希在事务前完成，事务中严格比较与已核验候选的全部原文，避免等待哈希使事务提前结束。没有覆盖、删除或修复旧历史；未知结果保留完整候选，重复保存同一文件不会生成新观察时间。

`/proposals/review-history` 独立获取当前可信绑定，不依赖建议仍可审核。原审核页、原审核恢复页和建议目录提供入口。目录按当前原绑定每页最多 20 份，按摘要键排序而非时间排序；只读事务读取完整页正文和目录，事务完成后逐份校验摘要，全部通过才展示目录。第 21 项仅判断续页，不作为已核验条目返回。选择条目后重读正文/所选摘要并重新核验 SHA-256；亦可按摘要直接读取。缺库不初始化，缺项不推断服务器结果，多页不构成跨页快照。

## 操作边界与剩余范围

历史面板与原请求保存、发送、查询共享互斥，开始历史操作撤销发送确认，期间不能并发发出审核。当前页的已确认回执与历史候选分离，保存/读取/导出异常保留既有内容；新载入成功后才替换历史候选。文件和浏览器历史可明确补存本地副本，但不会变成“本页刚收到”的可信响应。整体操作 30 秒，库打开/事务各 10 秒；文件读取或哈希迟到后不能继续写入，卸载中止等待并忽略迟到返回。

历史保存包含原请求但不自动写回原请求库，原审核或草稿逐份移除也不删除历史库。没有自动保存、整批历史备份/恢复/清理、容量保留、跨范围同步、服务器归档或旧记录迁移；仅新增浏览器库源码，未初始化实际库，无服务端 schema/依赖变化。R-009/P7-01 仍未完成，真实恢复与兼容证据待用户允许运行后补齐。
