# 手动草稿所选批量整理

2026-11-04，仅源码和人工审阅。未编译、类型检查、测试、运行产品/浏览器/接口/数据库或发布；运行与兼容证据仍缺。

同日共享机制增量：原手动服务及面板保留公开入口，内部改为薄适配调用 `saved-copy-cleanup.ts` / `saved-copy-cleanup-panel.tsx`，与原审核请求共用选择资格、摘要、完整预检/删除/读回及操作生命周期。各库仍自行提供编解码、双槽核验和备份模型；手动草稿继续要求并显示原saved_at，原库/格式/限额不变，跨种类文件不混用。

## 范围与入口

创建编辑器、审核编辑器及独立审核草稿恢复页新增 Select and remove manually saved copies from this page。先 Find saved drafts / Find saved review drafts 读取当前原网关与完整身份范围目录，再逐选或选择整页，最多20份。创建与审核分别使用原手动草稿库、原请求键与原备份格式，不读取自动副本、原提交、原审核、回执或远端建议。

整库超过100份仍可按当前页整理；本操作不计数或扫描完整集合。选择数量必须为1–20，不接受重复请求键。单份创建草稿仍限1 MiB、审核草稿32 KiB，所选规范文档分别限16 MiB和4 MiB，文件封装额外1024字节，目标正文累计同样有界。无法完整读取则拒绝整批，不能跳过损坏或超限项。

## 完整审阅和恢复文件

Inspect complete selected copies 在一个只读事务中读取所选全部正文和目录。每份须匹配选择时的完整目录摘要，并通过原双槽、绑定、请求键、正文和时间核验；缺项、半槽、变化或损坏均失败。所选摘要在异步打开数据库前转成独立字符串，避免读取中途使用变化后的选择。缺库不初始化，视为无法完成所选审阅。

按规范存储键排序后构造原手动备份文档，保留所有未完成字段、原请求键和原保存时间，规范SHA-256覆盖完整文档。面板保留已核验文档，可逐份展开全部内容；子集下载名称以 `-selected.json` 结尾，明确只包含所选草稿，不声称是完整范围备份。下载请求不证明文件已保存。已有手动备份加载、只读比较与确认恢复可接受该文件，只补文件所列缺项；不需要先恢复当前编辑器。

没有文件导入直接取得删除资格的入口。资格绑定当前目录数组、所选请求键集合、存储变化代次及已审阅文件摘要；选择、翻页、重新查找（包括失败）、存储变化、审阅或下载失败撤销资格及删除确认，但保留先前已读完整副本供导出。目录分页不是跨页快照；其他标签页的修改由删除事务重新检查。

## 独立确认与原子移除

用户独立确认已审阅所选完整内容后才能 Remove inspected browser copies。服务层重新核验完整文件、原绑定、规范摘要、确认摘要及1–20份上限，不信任页面显示结果。一个写事务先检查全部目标：双槽都缺失计入 `not_present`；完整正文（含原时间）及目录逐字相同才可删除；异文、半槽或损坏拒绝整批。

全部预检通过后才删除同文目标双槽，随后对所有所选键完整读回不存在，等待事务提交后返回 `total`、`removed` 和 `not_present`。库不存在返回全数 `not_present` 且不初始化。缺失只说明本次观察，不证明过去删除成功。事务提交之后其他页面的显式保存或备份恢复仍可重建副本，不提供永久删除保证。

删除尝试开始即撤销资格并清空相应目录、逐份删除确认及手动备份比较/恢复确认。失败、取消或超时可能已经提交，保留所选完整副本供导出；用户须重新查找、选择和审阅当前副本后才能再次删除，不能直接使用旧确认重试。创建端补手动存储变化代次，保存/单份移除/备份恢复/批量移除及目录重查均失效旧手动确认；审核端沿用既有共享代次。

## 操作生命周期

取得既有页面操作锁后同步暂停当前自动保存写者。整个文件核验及事务流程受30秒期限约束，打开数据库与事务各沿用10秒期限；离开面板取消等待、释放所持锁并忽略迟到结果。批量整理不替换当前编辑字段，不改变自动副本、已准备原请求或服务器审核状态。继续编辑仍使用原有权限、同建议/版本和同键原请求检查。

复用现有v1浏览器结构和手动备份格式，无新schema、迁移或依赖。后台自动清理、容量/时间保留策略、损坏槽修复、跨范围管理与运行证据仍待后续开发或验证。
