# 浏览器原同步查询完整备份与恢复（开发契约）

2026-11-03：仅源码与文档，未编译、类型检查、测试、运行浏览器/服务、访问 IndexedDB、生成样本或发布。新增独立共享文件格式，沿用现有 IndexedDB v1，无 API/schema/依赖/迁移变化；R-005 仍未完成。

## 入口与审阅

`/sync/receipt` 提供新标签页入口 `/sync/receipt/backup`，保留原页已经固定的查询。备份页不在加载时读取存储，也不查询服务器。用户可明确准备当前浏览器全部已保存原查询的备份，或打开已有备份文件进行完整核验；导入文件本身不恢复记录。

审阅固定完整文件，展示总条数、五字段原身份、事件 ID/类型和文档摘要；每屏 20 条仅为展示分页，下载和可复制 JSON 始终包含全部记录。准备下载不证明浏览器文件已保存。备份包括本浏览器同源 profile 中跨账号/项目的已保存原查询及完整事件正文，不包含未保存草稿、历史回执或本地队列。

恢复需要勾选本次全部记录的恢复意图，再明确点击恢复；每次尝试清除勾选。忙碌 ref 锁覆盖重新渲染前的重复操作，卸载取消等待。恢复成功和结果未知时均保留审阅文件供下载/复制，直到用户关闭；不自动重试、不将恢复结果当作远端投递确认。关闭审阅不访问存储。空文件可查看/下载，无需执行恢复。

## 独立文件格式与边界

共享 `SyncOriginalsBackupFile` 为 `{document,document_sha256}`。文档严格包含 `schema_version:1`、`kind:'workctx.sync-originals-backup'` 和 `entries`；每项为已有完整 `{identity,event}` 原查询。根和文件封套拒绝额外字段，原查询复用 `parseSyncEventReceiptQuery`。条目按 `JSON.stringify([tenant_id,workspace_id,project_id,actor_id,client_id,event_id])` 的字符串顺序严格递增，不接受重复槽或自动排序。事件内部属性顺序保留，不把重排正文当作原副本。

最多 256 条，完整文档最多 32 MiB，完整文件最多 32 MiB + 8192 字节；单条继续受原查询 1 MiB + 16 KiB 限制。完整 JSON 同时沿用 100000 节点和深度 64 限制，多个单独有效的原查询合并后仍可能超限。超限直接失败，不截断、不分批冒充完整备份；这些是单次操作边界，不是数据库总容量约束。

`document_sha256` 必须为 64 位小写十六进制，按规范文档 UTF-8 字节计算。共享解析只核验结构，浏览器通过 WebCrypto 独立重算摘要；恢复点击后再次解析完整文件并核验摘要，不直接信任先前审阅对象。文件声明大小、实际字节数和严格 UTF-8 解码均检查，可接受开头 BOM。摘要只表明文件内部一致，不认证服务器、原来源或实际投递。此格式只在专用备份页使用，不改变既有单条原查询/回执导入格式。

## 完整只读快照

`readBrowserSyncOriginalBackup` 在一个覆盖 `originals/directory` 的 readonly 事务内先读取两个存储的实际数量，要求相等且未超限；随后按原键遍历所有正文槽，完整读取并核验每一对正文/目录。键游标避免重复加载正文；每条核对规范原文、原身份/事件键、目录元数据及累计字节，终点核对实际已读数量并解析完整文档。

数量相等不能代替逐槽核验：目录与正文不同键、单边缺失、损坏、非字符串或不规范原文均整笔拒绝。空数据库返回空文档；数据库不存在时中止初始 upgrade，不永久创建空库。只有事务完成且未取消/超时才交付完整结果；摘要计算在事务结束后进行。

## 显式原子恢复

`restoreBrowserSyncOriginalBackup` 接收文件适配器已核验摘要的完整文档，再次结构解析并准备原槽、规范正文与目录。空文档返回零条结果，不打开数据库。非空恢复可在明确点击后初始化既有 v1 结构；初始化 upgrade 与数据恢复为不同事务，因此后续恢复失败仍可能留下空的 v1 存储。

数据恢复在一个 readwrite 事务中先逐条预检所有备份槽。两槽均不存在才列入待添加；已经存在的两槽须完整核验并与备份原文逐字一致。相同事件 ID 或相同元数据不能代替完整正文比较。异文、单边缺失或损坏均拒绝整批，预检完成前不添加任何记录。

全部预检完成后只用 add 写入缺失正文和目录，并逐条完整读回；所有请求在请求回调中同步排队，无事务内异步摘要等待。任一失败尝试 abort 整个事务；只有事务完成才返回 `restored` 或 `already-present`，并报告 total/restored/already_present。未涉及的其他记录保持原样，已有完整相同记录不重写；不执行 put、clear、删除、合并异文或损坏修复。事务完成后的其他标签页仍可改变记录，此结果不承诺未来状态。

## 期限与待补范围

文件读取、摘要和存储整笔操作有 30 秒单调期限；存储打开和事务分别沿用 10 秒期限。异步边界检查取消/期限，迟到文件/摘要结果不启动恢复事务；取消尝试终止已有事务。提交可能已经完成时保留“无法确认”及完整文件，不断言未写入。同步解析和浏览器结构化克隆不能硬实时抢占，不能在读取外部损坏值之前保证其大小。
