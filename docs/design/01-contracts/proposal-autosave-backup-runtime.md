# 自动草稿完整备份与恢复

2026-11-04，仅源码文档与人工审阅。未编译、类型检查、测试、运行产品/浏览器/接口/数据库或发布。

## 入口与范围

创建草稿区、审核草稿区及独立 `/proposals/recover-review-draft` 页增加 Back up or restore all automatic draft copies。分别读取当前原网关及tenant/workspace/project/actor/client精确绑定下的创建自动副本或审核自动副本，两类不混用。操作先取得原页面互斥并暂停当前自动写者；尚未持久化的当前字段不包含，取消中的保存却可能已经提交，不能据未确认状态推断备份是否包含新字段。需先等待自动保存确认或逐份审阅备份，也可另行导出当前文本。其他标签页的写者不会被全局暂停。

手动不可变快照、已准备原创建/审核、回执历史、worker队列及其他身份均不在自动副本备份范围；手动库继续使用自己的完整备份控件。历史敏感本地副本仍属于当前自动库集合；本机备份不是实时权限目录。恢复到另一浏览器仍须回到原完整绑定，文件内容不授予新权限。

## 格式与限制

文件封套为 `{document,document_sha256}`，document为 `{schema_version:1,kind,binding,entries}`。创建kind固定为 `proposal-editing-autosaves-backup`，审核固定为 `proposal-review-editing-autosaves-backup`。entries每项严格为 `{session_id,draft}`，保留原UUID v4自动会话和完整既有编辑草稿，包括原请求键、原保存时间、不完整原始字符串、来源/派生引用或原建议/版本/决定/理由。单份创建草稿仍限1 MiB、审核草稿32 KiB；不补默认值、不规范化编辑文字、不刷新来源或版本。

集合最多100会话，创建规范document最多16 MiB，审核最多4 MiB；完整文件各限document上限加1024字节。顶层、文档、条目和草稿全部严格校验，不接受未知/缺失字段、跨绑定、不同种类或损坏内容。按完整浏览器会话槽键严格递增，重复/乱序会话拒绝；同一请求键可能属于不同自动会话，均独立保留，不按请求键合并。槽键最多16 KiB，目录最多4 KiB。

规范SHA-256覆盖全部文档、kind、原绑定、会话ID、原文和时间；对象键排序、数组顺序保留。文件载入前检查size，读取后检查实际长度和字节预算，严格UTF-8解码，然后完整解析并重新计算摘要。比较及恢复也重新核验文件；摘要只证明内容一致，不认证作者、来源有效性、保存历史完整性或提交结果。文件名分别为 `proposal-editing-autosaves-backup.json` 和 `proposal-review-editing-autosaves-backup.json`。

## 完整读取与审阅

共享自动副本存储层在一个只读事务内计数该绑定的正文/目录，超过100或计数不一致即拒绝；随后遍历全部正文键，逐份完整核对正文、目录、会话寻址及绑定，并累计正文读取预算。到末尾核对实际读取条数，构造完整文档并检查包含封装字段的最终文档预算。孤立槽、半槽、内容/目录不符、损坏或超限均拒绝整个备份，不返回分页目录或部分结果。缺库返回合法空备份，不初始化。

界面保留完整已核验备份，可选择任意一项查看完整JSON，包括全部身份和草稿内容；一次显示一份正文，集合与比较仍覆盖全部会话。明确下载后保留页面备份，下载请求不证明文件已落盘。新载入/准备失败保留之前已核验的备份及当前输入，但撤销旧比较和恢复确认。准备只描述该绑定单事务快照，不表示永久内容或全设备历史。

## 只读比较与原子补入

比较只读取文件中的每个精确目标会话，返回missing、same或different。same必须包括原saved_at在内的完整正文及重建目录均一致；仅保存时间不同也为different。目标损坏或半槽令整次比较失败，不跳过。比较不初始化缺库、不写入，额外目标会话不参与对比；每次完整目标读取的累计正文预算与该种备份document预算相同，异文也计入预算。

用户独立勾选确认整个备份和比较后，才能 Restore missing automatic copies。确认绑定原文件摘要和本页存储变化序号，空备份不显示恢复按钮。恢复再次核验文件、原绑定和确认摘要，并在一个写事务内预检所有目标：双槽都缺失才列入新增，完整同文保留，任一异文/损坏拒绝整批。在全部预检完成后才逐份add双槽，最后完整读回全部源条目（包括原本已存在项），一致并等待事务提交才报告added/already_present。预检和读回各有独立完整目标正文预算；空集合不建库，非空显式恢复可初始化既有v1库。

恢复只补文件中的缺项，目标额外会话保留，不覆盖当前副本、草稿保存时间或目录，不改当前编辑器及确认。原会话ID保留，但当前编辑器不接管这些会话、不自动开启保存；逐份恢复编辑仍走原完整审阅/明确替换，以及创建的同键原请求检查或审核的同建议/版本/原审核检查，不准备或发送。

比较是当前观察，不锁定后续目标。恢复根据写事务里实际缺项补入；如果另一标签页已更新所选会话则冲突拒绝。如果另一写者持有与恢复副本完全相同的上次确认内容，恢复后它仍可继续更新自己原有的会话；文件保留捕获时的内容。显式恢复允许重建此前删除的副本，删除不是永久封禁。需要保留不可变历史时保留独立文件或手动快照。

## 失败、页面协调与剩余范围

备份操作与单份草稿读取/保存/删除/恢复及准备共享页面互斥，取得锁时同步暂停当前自动保存并撤销会话所有权。恢复尝试撤销当前确认，失效自动目录、旧单份移除资格及相关备份比较；创建草稿新增自动库变化序号，审核草稿沿用既有序号。单份自动副本移除同样撤销先前备份比较/确认。正文审阅和当前编辑文字保留，恢复后重新查找才产生新候选。

超时/取消或无法确认可能已经提交，保留完整备份及源文件，不显示已回滚；须重新比较并再次明确确认才能重试。already_present只表示本次观察，不追认上次提交结果。文件载入、摘要、比较/恢复合计30秒期限，数据库打开及事务各10秒；摘要后及事务前重查期限，卸载取消等待、忽略迟到结果并释放互斥。新备份界面保留本次取得锁的释放回调，父组件重渲染不会误取消在途操作。

共享固定模型/服务/面板接入两种库，单份自动保存格式、库名及版本保持不变，不执行迁移，不增加服务端schema或依赖。尚缺自动副本批量/自动清理、容量保留、定时备份、跨范围联合归档/远端同步及真实浏览器运行兼容证据。仅开发源码和文档及人工审阅，没有编译、类型检查、测试、执行产品/浏览器/数据库或发布。
