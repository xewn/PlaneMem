## 入口与身份

工作台 `/proposals` 的创建表单增加 Save editing draft、Export editing draft、Find saved drafts 和编辑草稿文件导入。需要创建能力；页面先读取可信 submission-context，将原网关、tenant/workspace/project、actor/client 绑定到编辑表单。身份读取失败时不展示可操作编辑表单，列表与已有建议详情仍可显示。绑定变化会重新挂载表单，不把旧编辑状态带到新身份。

准备原提交时，表单携带页面绑定；服务端调用既有预期身份读取再次核对，客户端也核对返回的完整原请求。账号、客户端、项目或网关发生改变时保留原编辑内容并拒绝准备，不自动迁移内容。保存编辑副本只操作本机浏览器或用户明确下载的文件，不调用创建、审核或模型接口。

## 编辑记录

独立v1格式为 `{schema_version:1,kind:'proposal-editing-draft',binding,request_key,saved_at,fields}`。它不是 `proposal-submission`，不能作为已准备原请求直接导入或提交。fields包含原表单字符串values、1–32条原来源字符串与可空origin引用（原proposal_id及revision字符串）。标题、内容、模型/作者过程、来源ID/URL、数字输入可留空或不完整；仅保存时执行严格结构/字段长度、已知类型/分类、原绑定/键和时间检查。准备时才调用完整创建契约校验。

正文最多131072字符，标题300，模型/提示版本各200，来源type64/id255/revision32/uri2048，TTL及派生revision字符串32；不含NUL或孤立代理字符。JSON输入及格式化文件均限1 MiB。保存不trim、不补默认值、不更新来源或原建议版本，不保存原审核批准、提交确认或准备/发送结果。读取不修复损坏字段，也不把文件内容当成当前权限或来源证明。

初始表单使用独立请求键；每次编辑字段、增删来源或修改派生版本产生新的随机请求键并撤销提交确认。保存、导出、载入同一编辑快照保留原键，避免仅因关闭页面而把同一内容换键。恢复后修改内容会产生新键；源快照始终保留。不同页面/浏览器的当前状态或实际提交结果不能由编辑文件证明。

## 浏览器快照

独立IndexedDB `planemem-proposal-editing-drafts` v1使用drafts和directory两槽，复用既有有期限/取消的浏览器事务工具。显式保存才初始化结构；读取缺库返回空目录，不升级或自动迁移。槽按规范原绑定/键限定，键最多16 KiB，目录元数据最多4 KiB。

保存为不可变快照：同一写事务读取双槽，仅在都不存在时同时add，随后完整读回并等待事务完成。已有相同字段保留首次浏览器saved_at；同键异字段、半槽、正文/摘要不符均拒绝，不覆盖或修复。保存确认失败时完整内容仍留在编辑器，可先重新查询目录，再重试相同快照或导出文件。浏览器清理、隐私模式、配额或其他设备无法保证保留这些副本。

目录每页最多20条，游标为原绑定下的上一页末尾请求键；按键顺序而非保存时间排列。每页完整核验最多20份正文与摘要，再返回标题/分类/时间等元数据；读取第21条目录键只用于判断续页。单份正文上限1 MiB，整次操作另受30秒期限约束。读取所选快照时再次核验完整双槽与原所选摘要，不用被替换的条目继续恢复。分页没有全目录快照，Find saved drafts回到第一页，重新查询可发现其他标签页的保存。

## 文件与明确恢复

导出当前编辑快照的完整JSON，触发下载只表示浏览器收到请求，不证明用户已将文件写入磁盘。导入有界读取完整文件、严格UTF-8解码及结构核验，并要求原绑定与当前表单一致。导入只载入候选，不自动保存到浏览器，也不修改当前编辑器。来源URL仅作为文本保存，不会自动访问。

候选展示标题、类型、来源条数、保存时间和可展开正文。用户须明确勾选替换当前编辑内容，再选择Continue from this copy。确认绑定当前编辑请求键；编辑后确认失效。当前没有restricted能力时拒绝载入restricted分类的候选。浏览器本地目录不是实时服务端权限目录，历史本地副本仍须按内容分类管理。

实际恢复前按同一绑定/键读取已准备原请求的浏览器及旧标签页槽。若存在，必须与编辑字段规范化后的完整创建草稿一致；两处原请求矛盾或正文不匹配则拒绝。匹配时转入既有原请求恢复界面，不自动保存/提交，也不开放原请求字段修改。未发现本地原请求时才替换编辑字段、保留原键并撤销提交确认；派生原建议的旧状态/期限/来源有效性提示不继承，要求重新打开当前原建议核对。

本地未找到原请求不证明从未准备或提交，其他设备/导出文件/并发标签页仍可能保留原请求。存在未知提交时应使用原请求恢复与回执查询；编辑副本不提供全局锁或自动解除未知结果。准备与发送仍走既有身份、保存和回执检查。

文件读取和浏览器操作共用30秒本地等待期限，数据库打开/事务各沿用10秒；离开表单取消未完成等待并忽略迟到结果。手动保存/加载期间锁定编辑、准备及其他草稿操作，不跨等待覆盖新编辑内容；下述自动保存不锁定输入。目录损坏、存储不可用或恢复校验失败保留当前文本及原文件。

## 逐份移除浏览器副本

2026-11-04 增量：从浏览器目录选择并完整载入草稿后，可展开全部字段、Export selected copy，或独立勾选后 Remove selected browser copy。此确认与替换当前编辑器的确认分开；选择另一份浏览器副本或文件时撤销两个确认。文件导入候选只提供导出和继续编辑，不能直接触发浏览器删除。导出所选副本不要求先替换当前编辑内容。

移除仅针对独立编辑草稿库中的精确原绑定/请求键。写事务重新验证完整正文及目录，并与已审阅内容逐字比较，包括原保存时间和所有字段；一致才删除双槽，完整读回确认为不存在后等待事务提交。库不存在时不初始化，两个槽都缺失返回not-present，仅表示本次观察中已不存在，不证明任何先前删除成功。半槽、损坏、同键内容或保存时间变更均拒绝，不能据此修复或清理其他记录。

移除尝试开始即撤销删除和替换确认，并清空当前目录视图；无论成功、缺项或未知，已审阅的完整候选仍保留，可复制、导出或另行确认继续编辑。当前候选不直接重复删除，须 Find saved drafts 后重新选择完整副本；超时/取消可能已提交，不能显示为回滚或确定失败。恢复编辑仍检查同键原请求，保存编辑副本仍采用原不可变内容规则。

操作共用既有编辑锁与30秒期限、事务10秒期限，离开组件忽略迟到结果。不会清空当前编辑器、删除已准备原请求或回执、取消/撤销服务器建议，也不会访问下载文件、其他绑定或其他设备。保留的页面审阅内容只持续到离开页面、继续编辑或选择另一份候选，需用户明确导出才能留下独立文件。删除提交之后其他标签页仍可重新保存相同槽，成功结果仅描述本次事务，不保证永久缺失。

可选择开启的自动保存见末节；仍没有批量删除/容量和保留管理、跨范围全库备份、跨身份迁移、远端草稿同步或自动来源刷新。当前绑定范围的手动快照完整备份见下节。逐份移除复用既有浏览器结构，无Gateway、服务端数据库或依赖变更；只有源码及人工审阅，运行与兼容证据仍待后续。

## 当前范围完整备份与恢复

2026-11-04 增量：编辑器的 Back up or restore all manually saved editing drafts 支持显式准备完整浏览器备份、下载保留文件、载入文件、只读比较、确认后补入缺失副本。备份只包含当前可信网关及tenant/workspace/project/actor/client精确绑定下手动保存的编辑快照；独立自动副本、当前未保存表单、其他身份、已准备原提交、回执与worker队列均不包含。敏感分类的历史本地副本也属于该集合，备份不是实时服务端权限目录；继续编辑仍沿用既有分类能力与原请求检查。

v1文件为 `{document,document_sha256}`，document是 `{schema_version:1,kind:'proposal-editing-drafts-backup',binding,entries}`。每条entries为完整既有编辑草稿，包括不完整原字符串、派生引用、请求键和原saved_at。按浏览器存储键的字符串顺序严格递增，拒绝重复/乱序/跨绑定；顶层和各草稿均执行严格结构校验。规范JSON按对象键排序，数组顺序保留；SHA-256覆盖完整document，读文件、比较及恢复都重新核验，字段顺序变化不影响摘要。摘要证明内容一致性，不认证来源、完整历史或服务器状态。

上限100份草稿、16 MiB规范document，完整文件限16 MiB加1024字节；单份草稿仍限1 MiB且满足原格式化大小限制，元数据4 KiB、槽键16 KiB。文件在读前检查size，读后检查实际字节数、严格UTF-8、完整JSON与摘要；不接受截断结果。导出为紧凑完整JSON，不把分页目录或摘要列表当作备份。下载请求不证明磁盘已保存，须用户确认文件落盘。

准备备份使用一个只读事务：先计数当前范围双槽，计数不等、超过100份或读取损坏均失败；遍历全部正文键并完整验证对应目录，累计正文预算，最终核对实际条数及包含封装的文档预算。正文与目录的计数和完整配对核验共同检查范围内的遗漏/孤项。缺库返回合法空备份且不初始化；超限不返回部分备份。“完整”只描述本次绑定范围内单事务快照，不保证另一个时间或设备的内容。

比较重新核验文件，随后单个只读事务检查源文件中每个精确目标槽：missing、same或different。same要求包括原saved_at在内的完整规范正文与目录相同，仅保存时间不同也按冲突处理；半槽/损坏使整次比较失败，不返回部分通过。每次完整目标扫描正文累计最多16 MiB；被比较的本地内容即使不同也受预算限制。比较不创建缺库、修复记录或写入，且只覆盖文件所选键，不能证明其他本地槽完整。

用户确认绑定已审阅文件摘要，实际恢复重新核验文件与摘要、重新检查所有目标；单个写事务内先完成全部预检，再只对双槽缺失项add，已有同文保留、异文或损坏整批拒绝。全部源条目（含本来已存在项）完整读回一致后才确认提交。预检与最终读回各有16 MiB目标正文预算，恢复最多两次完整扫描，另外的源文件验证仍受文档上限；空备份不建库，显式非空导入可初始化既有v1编辑库。目标额外草稿不删除，不覆盖时间或正文，也不碰原请求库。

比较属于当前观察，不锁定未来目标；恢复根据同一写事务中的实际缺项补入。导入开始撤销确认和目录视图，结束后须重新Find saved drafts；当前编辑字段和已审阅单份候选继续保留。导入失败/超时可能已提交，保留完整备份和源文件，不显示已回滚；需重新比较、再次明确确认，返回already_present只表示本次已存在，不追认上次导入成功。文件更换或重新比较都会撤销原确认；载入新文件失败仍保留先前已核验备份并明确提示。

文件读取、摘要和浏览器操作统一30秒期限，数据库打开/事务各10秒；摘要后与事务前重新检查期限，离开组件取消等待并忽略迟到结果，异步操作期间共享编辑器操作锁。恢复只补本地编辑草稿，不自动打开、修改或发送建议；后续继续编辑仍需逐份审阅。该手动备份功能无新增浏览器版本/服务端schema/依赖，只改源码与文档，未编译、类型检查、测试、运行浏览器/接口/数据库或发布。跨范围联合备份、后台清理及运行证据仍待后续。

自动写入串行执行，不锁定输入，也不会因为每次输入都取消已开始事务。保存确认对应捕获时的完整绑定/键/字段；若期间继续编辑，只更新内部上次确认副本，再安排最新字段保存，不把旧回执显示为当前字段已保存。状态分别说明等待、保存中、已确认和无法确认。准备期间不启动新自动写入；转入固定原请求、离开或绑定变化重新挂载时取消等待并忽略迟到结果。不依赖卸载时的异步补存，关闭前仍在等待的输入可能尚未保存。

手动保存、导出、查找、审阅、删除、恢复或整批备份操作在取得既有编辑锁后同步暂停自动保存；暂停清除会话所有权并取消未完成等待。取消/超时/校验或配额失败可能已经提交，因此停止自动写入并保留页面文字，提示导出或查询自动目录；不得显示已回滚。用户再次开启创建独立会话，不覆盖结果未知的旧槽。当前restricted能力不足时不允许开启，已开启期间失去能力则停止自动保存；页面原绑定与实际提交时身份核对继续适用。
